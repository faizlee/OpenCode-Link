# 任务文件预览实施合同

> Feature：`THREAD-FILE-PREVIEW-001`
> 状态：`implementation_verified` / 已获 2026-08-29 当前对话实施授权
> 目标分支：`codex/task-file-preview`

## 真实用户成果

用户在手机或电脑浏览任务时，点击回答里引用的本地截图、PDF 或文本文件，不再进入打不开的电脑路径，而是在当前任务上方直接预览。关闭预览后回到原来的对话位置；需要原文件时仍可下载。

## 用户界面

- 手机使用接近全屏的覆盖层，电脑使用居中弹窗。
- 图片显示可缩放的大图；PDF使用同源内嵌阅读；文本、Markdown、日志、JSON和常见代码以只读文本显示。
- Word、Excel、PowerPoint及其他未可靠支持的格式显示名称、类型、大小，并提供下载或用其他应用打开。
- 顶部始终提供文件名、下载原文件和关闭；按 `Escape` 也可关闭。
- 加载失败、文件已移动或临时附件已清理时显示真实原因，不留空白弹窗。
- 普通网页链接不进入文件预览层。

## 安全与状态 Owner

- 服务端文件预览登记表是唯一授权 Owner；浏览器不能用查询参数提交任意本地路径。
- 只有当前任务消息明确引用的文件才会获得随机、短生命周期预览令牌。
- 文件必须真实存在，并在当前任务 `cwd` 或 OpenCodex Link `uploads` 根目录内；使用规范化真实路径阻止 `..` 和符号链接越界。
- 所有预览和下载请求继续要求有效的受信任设备会话。
- HTML、SVG和未知主动内容不内联执行；不支持格式只能下载。
- 令牌只在内存中保存，服务重启或到期后通过重新打开任务重新登记，不建立新的永久文件索引。
- 既有24小时临时附件清理规则不变。

## 实现节点

1. 读取当前任务时，服务端扫描代理消息中的 Markdown 文件链接。
2. 解析绝对或相对本地路径，验证真实路径、允许根目录和文件类型。
3. 为合格文件登记随机预览令牌，并把 Markdown 目标改写为同源 `/api/files/:token`。
4. 认证后的文件接口提供安全的内联响应、纯文本响应或下载响应。
5. 手机界面自定义 Markdown 链接与图片渲染；内部文件链接打开预览层，外部链接保持原行为。

## 验收

- 未配对请求获取预览或下载返回 `401`。
- 任意路径、任务未引用路径、`..` 越界、符号链接越界、过期令牌和已删除文件均不能读取。
- 图片、PDF和文本链接进入预览层；不支持格式显示文件信息并可下载。
- HTML与SVG不会在预览层执行。
- 关闭弹窗后对话滚动位置不变化；手机390px无横向溢出，关闭和下载操作可达。
- 原有消息显示、外部链接、附件发送、设备认证、任务刷新和桌面管理台不回归。
- 通过类型检查、单元测试、构建与真实浏览器交互验证。

## 停止线

不得为了预览开放任意文件路径、整个项目之外的电脑目录、无认证静态目录或可执行主动内容；不得改变临时附件清理规则或建立云端文件库。
